# 시즌 전환 점검표

리그마다 시즌이 바뀔 때 생기는 일과, 자동으로 처리되는 것·사람이 확인할 것을 정리한다.
문제가 생기면 대부분 **이상 감지 메일**(문의 받는 주소로 옴)이 먼저 알려 준다.

## 자동으로 처리되는 것
| 일 | 어떻게 |
|---|---|
| 새 시즌 일정 받기 | 각 수집기가 '지금 기준' 시즌·기간을 받는다 (football-data·ESPN 현재 시즌, KBO·K리그 올해, KBL 날짜 범위, V-리그 연맹이 정한 현재 시즌, F1 `current`) |
| 새 시즌 시작 전 빈 순위표 | 출처가 빈 표를 주면 저장하지 않고 지난 시즌 표를 그대로 둔다 |
| 승격·강등 | 리그 순위표에 나온 팀은 그 리그 소속으로 바꿔 보여 준다 (`team.current_competition_id`, 시드는 그대로) |
| 처음 보는 팀 | 경기 상대로 자동 등록되고, 리그 경기에 나오면 **"한국어 이름 필요" 메일**이 온다 → 관리자 → 팀 이름에서 고친다 |
| 수집이 멈추거나 연속 실패 | 이상 감지 메일 (같은 문제는 12시간에 한 번) |

## 시기별로 사람이 확인할 것
| 시기 | 확인할 것 |
|---|---|
| 2월 말 K리그 개막 | 승격팀이 K리그1 순위표·팀 선택에 들어왔는지. 신생 구단이 생기면 `data/seed/korea-football.json` 에 추가 |
| 3월 KBO·F1 개막 | KBO 일정·순위가 새 시즌으로 바뀌었는지. F1 새 드라이버의 한국어 이름을 `src/lib/f1names.ts` 에 추가. 고를 수 있는 F1 팀·드라이버 목록은 `data/seed/f1.json` 과 `src/lib/f1picks.ts` 를 함께 고친다 (팀 이름이 바뀌면 `match` 에 새 이름 추가) |
| 8월 유럽 축구 개막 | 승격팀 한국어 이름 (메일로 알림). 이적한 국내 중계권이 있으면 시드의 `broadcast` 수정 |
| 10월 KBL·NBA·NHL 개막 | KBL 남은 경기 중계 채널이 채워지는지, NBA·NHL 순위표가 새 시즌인지 |
| 10월 V-리그 개막 | 일정·순위가 새 시즌으로 바뀌었는지. 팀이 바뀌었으면 `data/seed/korea.json` 의 `refs.kovo` 수정 (예: 페퍼저축은행 → SOOP 처럼 구단 코드가 바뀔 수 있다) |
| 매년 | 국내 중계권 변경 확인(시드 `broadcast`), Cloudflare Worker 의 GitHub 토큰 만료일(1년), 도메인 자동 연장(가비아) |

## 시드에 정식 팀으로 넣는 방법
처음 보는 팀은 경기 상대로만 자동 등록되어 팀 선택 목록에는 나오지 않는다(한국어 이름을 고치면 나온다).
팀 선택 목록·팀 페이지에 확실히 넣으려면 `data/seed/*.json` 의 `teams` 에 slug·한국어 이름·영문 이름·출처별 팀 ID(`refs`)를 추가한다. 유럽 축구 팀은 홈 경기장 `venue`·`venue_city`("London, England")도 넣는다 (football-data 는 경기장을 주지 않아 이 값을 쓴다).
