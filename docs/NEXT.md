# 다음 작업 후보 (2026-10-29 기준, 아직 정하지 않음)

여기 적힌 일은 사용자가 고르면 진행한다. 끝난 항목은 지우고, 새로 나온 제안은 추가한다.

1. **F1 세션 고르기**: 팀·드라이버를 고르면 연습 주행(FP1~3)·스프린트 예선까지 모두 캘린더·알림 메일·구독에 들어간다 (주말마다 최대 7개). '결승·예선·스프린트만' 옵션을 추가할지
2. **KBO 순연 처리 지켜보기**: `upsert.ts` 가 출처에서 사라진 옛 일정을 지우거나 취소로 바꾼다. 포스트시즌 중 경기가 사라지거나 두 번 나오면 `sync_run` 과 `upsert.ts` 부터 확인. 10/29 점검: 공식 일정과 같음. 한국시리즈 일정이 올라오면 한 번 더 보고 끝
3. **회사 컴퓨터 로컬 DB 복구**: `.data/pglite` 가 켜지지 않는다("Aborted()"). 사용자에게 물어본 뒤 폴더를 지우고 `npm run db:setup`
4. **검색엔진 후속**: Search Console '이벤트 location 누락' 수정 확인 결과 확인. 리그 페이지에도 경기 구조화 데이터(SportsEvent)를 넣을지
5. **새 기능 이용 확인**: 며칠 뒤 관리자 현황에서 기록지·리그 일정 탭 이용 수 보기
6. **시즌 전환 준비**: KBO·MLB 비시즌 진입. 점검표는 `docs/SEASON.md` (유럽 축구 새 팀은 `venue`·`venue_city` 도)
7. **캘린더 구독 안내 강화**: 팀을 고른 직후 '휴대폰 캘린더에 추가'를 가장 눈에 띄게 (기기별 방법 안내). 캘린더 앱 알림이 무료이고 메일보다 정확해서 핵심 기능으로 민다. 알림 메일은 그 아래 선택지로 (메일 비용 논의 2026-10-29: 무료 한도 하루 100통 ≈ 메일 켠 사람 70~80명, 넘으면 Amazon SES 가 월 몇 달러 수준)
